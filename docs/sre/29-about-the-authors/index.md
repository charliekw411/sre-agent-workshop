## Acknowledgements

The structure, navigation, and publishing pipeline build on an earlier
[Azure-hosted .NET workshop](https://azure.github.io/aca-dotnet-workshop/). If
you found this workshop easy to follow, a good share of the credit belongs to
that project's authors, who worked out the format first.

## Contributing

Contributions are welcome. The highest-value contributions are, in order:

1. Screenshots. The module pages contain `<!-- SCREENSHOT: ... -->` markers where captures belong, and the workshop reads far better with them.
2. Corrections to commands that no longer work as Azure services evolve.
3. Additional safe failure scenarios that use authenticated Azure control-plane
   operations and teach something the CPU and data-disk incidents do not.
4. Improvements to the visual correlation between endpoint activity, VM
   metrics, application telemetry, alerts, and SRE Agent investigations.

See [CONTRIBUTING.md](https://github.com/charliekw411/sre-agent-workshop/blob/main/CONTRIBUTING.md) for the process, and read the [Markdown and writing conventions](https://github.com/charliekw411/sre-agent-workshop/blob/main/CONTRIBUTING.md#documentation-standards) before opening a pull request.

## Reporting problems

* Something in the workshop does not work: open an issue with the module number, the command you ran, and the full error.
* A security concern with the sample application or infrastructure: follow [SECURITY.md](https://github.com/charliekw411/sre-agent-workshop/blob/main/SECURITY.md) rather than opening a public issue.
* A question about Azure SRE Agent itself: use the [official documentation](https://learn.microsoft.com/azure/sre-agent/) and Azure support channels.
